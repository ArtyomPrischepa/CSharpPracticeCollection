• Базовый запуск: Метод task1.ContinueWith(t => { ... }) создает задачу продолжения.
Она автоматически стартует только после завершения task1.

• Связующий параметр: Принимаемый в лямбду параметр t — это объект предыдущей задачи.
Через него можно узнать её свойства, например t.Id.

• Передача результата: Если предыдущая задача возвращает значение (Task<TResult>),
то следующая задача может забрать этот результат через свойство t.Result.

• Цепочки: Можно вызывать .ContinueWith() один за другим,
выстраивая последовательный конвейер обработки данных.
