Существует два основных способа написания LINQ-запросов:
1. Операторы запросов (Query Syntax) — внешне напоминают SQL-запросы.
Пример: from p in people where p.StartsWith("T") select p;
2. Методы расширения (Method Syntax) — использование цепочки методов с лямбда-выражениями.
Пример: people.Where(p => p.StartsWith("T"));
Базовые методы/операторы:
• Where / where — фильтрация элементов по условию.
• OrderBy / orderby — сортировка по возрастанию.
• Select / select — определение того, какие именно данные попадут в финальный результат (проекция).
