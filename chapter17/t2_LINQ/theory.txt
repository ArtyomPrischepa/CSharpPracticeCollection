Проекция позволяет преобразовать объект одного типа в объект другого типа, либо выбрать из объекта только определенные свойства.
Существует два основных подхода:
1. Оператор select (LINQ-запросы): Используется для создания новой формы данных. Можно выбирать как отдельные свойства, так и создавать новые объекты (включая анонимные типы).
2. Метод расширения Select(): Принимает лямбда-выражение u => u.Property, трансформируя каждый элемент коллекции.
Дополнительные инструменты:
• Оператор let: Позволяет вводить промежуточные переменные внутри LINQ-запроса для дополнительных вычислений.
• Метод SelectMany(): Используется, когда у вас есть "коллекция коллекций" (например, список компаний, у каждой из которых есть список сотрудников). Он «сплющивает» (сводит) их в один плоский список.
