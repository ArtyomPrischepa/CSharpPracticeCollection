Класс Task из библиотеки TPL (Task Parallel Library) предназначен для упрощения работы с многоядерными процессорами
и представляет собой отдельную продолжительную операцию, которая обычно выполняется асинхронно в потоке из пула потоков.
Важно помнить: задача — это не поток.
------------------------------
## 1. Способы создания и запуска задач
Существует три основных метода создания и инициализации задач:

* Классический через new: Требует явного вызова метода Start().

Task task = new Task(() => Console.WriteLine("Hello Task!"));
task.Start();

* Через фабрику Task.Factory.StartNew(): Создает и сразу запускает задачу. Возвращает объект Task.

Task task = Task.Factory.StartNew(() => Console.WriteLine("Hello Task!"));

* Через метод Task.Run(): Современный стандартный способ. Также сразу запускает задачу.

Task task = Task.Run(() => Console.WriteLine("Hello Task!"));


------------------------------
## 2. Ожидание завершения и синхронный запуск
Задачи по умолчанию выполняются асинхронно, из-за чего основная программа может завершиться раньше, чем отработает код в задаче.

* Метод Wait(): Блокирует текущий (вызывающий) поток до тех пор, пока задача не завершит свое выполнение.
* Метод RunSynchronously(): Позволяет запустить задачу синхронно, выполняя её прямо в текущем потоке (вместо пула потоков).

------------------------------
## 3. Ключевые свойства класса Task
Класс Task предоставляет набор свойств для мониторинга его состояния:

* Id: Уникальный идентификатор текущей задачи.
* IsCompleted: true, если задача завершена (успешно, отменена или из-за ошибки).
* IsCompletedSuccessfully: true, если задача завершилась без ошибок и отмен.
* Status: Текущее состояние задачи
(принимает значения из перечисления TaskStatus, такие как Created, Running, RanToCompletion, Canceled, Faulted и др.).
