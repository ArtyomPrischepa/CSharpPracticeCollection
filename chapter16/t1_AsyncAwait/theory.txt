• Модификатор async: Ставится в заголовке метода перед возвращаемым типом.
Он не делает метод асинхронным автоматически, а лишь разрешает использовать внутри оператор await.

• Оператор await: Указывается перед асинхронной операцией (например, Task.Delay).
Он приостанавливает выполнение метода, пока задача не завершится, освобождая текущий поток для других нужд.

• Возвращаемые типы: Если метод ничего не возвращает, вместо void используется Task.
Это позволяет вызывать метод с ключевым словом await.

• Неблокирующая задержка: Вместо Thread.Sleep(мс) в асинхронном коде применяется await Task.Delay(мс).
Она замораживает конкретную задачу, но не блокирует системный поток.

• Параллельный запуск: Чтобы запустить задачи одновременно, вызовите асинхронные методы без await
и сохраните ссылки на них в переменные (var task1 = MethodAsync();).
Примените await к каждой переменной позже, когда потребуется дождаться результата.

• Асинхронная лямбда: Определяется через связку с делегатами Func или Action,
где перед параметрами указывается async, а возвращаемым типом служит
Task (например, Func<string, Task> handler = async (msg) => { ... };).
