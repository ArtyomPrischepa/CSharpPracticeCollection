1. async Task<T> — используется, когда асинлекронный метод должен вернуть результат (объект, число и т.д.).
Значение внутри метода возвращается через стандартный return,а вызывающий код получает его с помощью await.

2. async Task — используется, когда метод выполняет асинхронную работу,
но результат не возвращает (аналог асинхронного void).
Позволяет использовать await при вызове, чтобы дождаться завершения операции.

3. async ValueTask<T> — структура (структурный тип), которая оптимизирует работу с памятью в хипе (куче).
Идеально подходит, если результат операции часто уже готов (доступен синхронно)
и создавать тяжелый объект Task не нужно.

4. async void — используется только для обработчиков событий (event handlers).
Его нельзя вызвать через await, а возникающие внутри исключения невозможно перехватить снаружи
(что приводит к падению приложения). В обычном коде его следует избегать.
