Асинхронные стримы (Async Streams) в C# решают проблему передачи множества элементов из асинхронного источника
без блокировки вызывающего потока и без предварительной загрузки всей коллекции в память.

1. Суть концепции: До C# 8.0 асинхронный метод (async/await) мог возвращать только один объект за раз,
а синхронные итераторы (yield return) блокировали поток выполнения. Асинхронные стримы объединяют эти подходы.

2. Как создать (Producer): Метод должен иметь модификатор async, возвращать интерфейс IAsyncEnumerable<T>
и использовать ключевое слово yield return для последовательной отдачи элементов по мере их готовности.

3. Как прочитать (Consumer): Для перебора асинхронного стрима применяется специальный цикл await foreach.
