1. Базовая обработка (async Task): Чтобы поймать исключение из асинхронного метода,
выражение await должно находиться внутри блока try..catch.

2. Проблема async void: Если метод возвращает void,
исключение нельзя перехватить снаружи через try..catch во внешнем методе — программа аварийно завершится.
Ошибки в async void нужно обрабатывать внутри самого метода.

3. Состояние задачи (IsFaulted): У объекта Task при ошибке свойство IsFaulted принимает значение true,
а само исключение находится в task.Exception.InnerException.

4. Множественные исключения (Task.WhenAll):
При параллельном запуске нескольких задач через WhenAll оператор await перехватит только первое исключение.
Чтобы получить все возникшие ошибки, нужно использовать коллекцию Exception.InnerExceptions самого объекта Task
(который возвращает WhenAll).
