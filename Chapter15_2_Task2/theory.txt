## Вложенные задачи (Nested Tasks)

* Независимость по умолчанию: Внутренняя задача выполняется отдельно от внешней.
* Привязка к родителю: Флаг TaskCreationOptions.AttachedToParent делает внутреннюю задачу частью внешней.
    var outer = Task.Factory.StartNew(() =>      // внешняя задача
    {
        Console.WriteLine("Outer task starting...");
        var inner = Task.Factory.StartNew(() =>  // вложенная задача
        {
            Console.WriteLine("Inner task starting...");
            Thread.Sleep(2000);
            Console.WriteLine("Inner task finished.");
        }, TaskCreationOptions.AttachedToParent);
    });
    outer.Wait(); // ожидаем выполнения внешней задачи
    Console.WriteLine("End of Main");
* Ожидание: Внешняя задача не завершится, пока выполняются прикрепленные к ней вложенные задачи.

## Массив задач (Task Array)

* Запуск пула задач: Можно запускать группы задач через циклы или коллекции.
* Синхронизация по всем: Task.WaitAll(tasks) блокирует поток до завершения всех задач.
* Синхронизация по первой: Task.WaitAny(tasks) ожидает завершения хотя бы одной задачи из массива.
* Порядок выполнения: Очередность выполнения задач в массиве не гарантирована (недетерминирована).

## Возвращение результатов

* Generic-класс Task<T>: Используется для задач, возвращающих данные типа T.
* Свойство Result: Хранит возвращенное значение.
* Блокировка потока: Обращение к .Result останавливает текущий поток до окончания работы задачи.
